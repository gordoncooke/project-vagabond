Enable Trusted HTTPS

The Offline Library operates without Internet access and therefore uses its own local certificate authority for HTTPS.

1. Download the certificate

Install this certificate only if you trust this Offline Library device.

Download Offline Library Root Certificate

File: OfflineLibraryRootCA.cer

2. Install and trust the certificate

Your device will require you to explicitly install or trust the downloaded certificate.

Installing a root certificate gives it authority to verify secure connections. Only install this certificate on devices where you intend to use this Offline Library.

3. Open the secure library

After installing the certificate, use:

Open Secure Offline Library

https://library.local/
